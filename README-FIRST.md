# Personal KB 0.3 试用版

这是一份可以运行的本机安装包。Windows 使用 x64 包；Mac 使用 Apple 芯片包，系统需要 macOS 14 或以上。此版不支持 Intel Mac。首次需要联网，约 2.3 GB 的检索模型可稍后准备。

## 开始试用

1. 从 [README 下载入口](README.md#首次使用) 取得平台安装包。Windows 在资源管理器选择 **“全部解压”**；Mac 在 Finder 双击 ZIP。等待解压结束，进入新文件夹，不要在压缩包内运行。
2. **双击 `install.cmd`（Windows）或 `install.command`（Mac）**。此时会出现终端窗口，程序使用包内 uv 准备私有 Python 和基础依赖。首次需要联网，无需预装 Python、Git 或手动打开 CMD 输入命令。
3. 基础服务启动成功后，自动打开 **“Personal KB · 本机安装与状态”** 网页。你会看到“本机连接”“按需要准备功能”“后台任务”和使用示例；安装时没有选择笔记库的页面，也不用填写 API Key。
4. 点击 **“安装并接入 WorkBuddy”**。程序备份已有配置，合并本项目连接条目，保留其他 MCP；页面显示配置已保存，等待客户端连接。
5. 回到 WorkBuddy 的连接器管理，找到 `obsidian-personal-kb-host`，完成它要求的原生信任。没有出现时刷新连接器或重启 WorkBuddy。安装器不能替你点击信任；仅“配置已保存”不代表已经连通。
6. 在 WorkBuddy 发送下面的消息，开始第一次文字整理。无需先下载检索模型或视频组件，也无需再发第二轮安装指令。

```text
把下面内容整理成一篇 Obsidian 笔记。
笔记库绝对路径：D:\Obsidian\工作库
分类目录：技术研究\RAG
内容：增量索引只处理新增、修改和删除的文件，减少重复计算。
使用 personal-kb 工具完成保存，告诉我实际文件路径。
```

请替换为已经存在的库路径。Mac 示例：`/Users/你的用户名/Documents/工作库`。分类目录可以不存在，程序会在该库内创建。下次可以指定另一个库、另一个目录。生成的文件标为 `staged`，在 Obsidian 审核后可手动改为 `promoted`。

这一条消息的程序流程是：WorkBuddy 调用 `ingest_content_prepare` 绑定目标库和目录，使用返回的提示生成 Markdown，再调用 `ingest_content_finalize` 保存草稿并返回实际路径。安装器不自动安装或注册 Skill；这里由 AI 调用已接入的 MCP 工具。请在 Obsidian 打开返回的文件，确认保存结果；握手成功本身不能证明这一步已完成。

## 导入原有笔记

在安装页面点 **“准备语义检索”**，可关闭网页，后台继续下载依赖和模型。出现“已就绪”后，在 WorkBuddy 发送：

```text
为 D:\Obsidian\工作库 建立检索索引。
包含全部子目录的已有 Markdown，包括没有 status 字段的旧笔记；
排除 日记 和 模板 两个目录，保留原文件，以后自动同步。
如果是后台任务，先告诉我任务编号和状态。
```

WorkBuddy 调用 `start_index` 后，程序按你明确授权的范围建立本机向量数据库，不改原笔记。仅准备好模型不会自动扫描所有库。`staged`、无效元数据、隐藏文件和链接目录不收录。已明确纳入的普通旧笔记会标识为“用户导入”，不会冒充人工审核。之后可说：

```text
只检索 D:\Obsidian\工作库 的技术研究目录，回答增量索引怎么工作，并引用原笔记路径。
```

每个库分别保存索引范围和向量数据库。同库再次指定索引范围会**替换**原范围；查询时指定目录只是在现有范围内缩小检索。自动同步约每 30 秒检查一次；大库初次索引仍需要时间。长任务立即返回编号，WorkBuddy 可以查询进度，不需要在聊天内持续执行安装命令。

## 重开、恢复与视频

- 关机或停止服务后，再次双击安装入口。也可以使用安装目录内的 `Open Personal KB.cmd` / `.command`。重复打开会复用缓存和当前服务，此版不设置开机自启。
- 下载失败或任务中断：重新打开，在“后台任务”点击“继续 / 重试”。基础启动阶段失败则重新运行安装入口。
- 视频是可选功能：准备视频组件；有字幕时优先使用字幕。音频识别需要在页面保存你自己的 DashScope Key，相关音频会发送到该服务，服务费用以账户实际规则为准。不要把 Key 发到聊天里。
- 默认数据目录：Windows `%LOCALAPPDATA%\PersonalKB`；Mac `~/Library/Application Support/PersonalKB`。凭据、任务和向量库都在其 `data` 子目录。页面“维护与退出”可以停止服务。

## 已知试用边界

此包未做代码签名，也不是完全离线安装器。Windows 启动、WorkBuddy 特定版本的热加载与原生信任仍需实机反馈；配置保存不代表已经信任或连接。若旧版本配置也使用 `obsidian-personal-kb-host`，程序会拒绝覆盖，需在 WorkBuddy 中给旧条目改名或移除后再点接入。

2026-10-03 的 Apple 芯片 Mac 首次安装观察已确认基础服务就绪、配置保存、语义模型下载和本地加载、视频组件准备成功，也记录到客户端握手；客户端身份与原生信任操作未被独立确认。真实笔记保存 / 检索闭环、云端 ASR 和大型库性能仍待验证。完整范围见 [README](README.md#验证范围与试用边界)。原 ZIP 保持不变，仓库中的说明可能比包内版本更新。

仅处理你在对话中明确指定的路径。不要让 WorkBuddy 在沙箱中运行安装脚本；由你双击启动的本机服务承担安装、索引和视频任务。
