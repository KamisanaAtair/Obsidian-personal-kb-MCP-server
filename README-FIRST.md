# Personal KB 0.3 试用版

这是一份可以运行的本机安装包。Windows 使用 x64 包；Mac 使用 Apple 芯片包，系统需要 macOS 14 或以上。此版不支持 Intel Mac。首次需要联网，约 2.3 GB 的检索模型可稍后准备。

## 开始试用

1. **完整解压 ZIP**，不要在压缩包内运行。Windows 双击 `install.cmd`；Mac 双击 `install.command`。无需预装 Python、Git 或手动打开 CMD。
2. 首次出现终端窗口，自动准备基础环境，成功后打开本机浏览器界面。点击 **“安装并接入 WorkBuddy”**，程序会合并连接配置并保留其他 MCP。
3. 回到 WorkBuddy 的连接器管理，找到 `obsidian-personal-kb-host`，完成它要求的原生信任。没有出现时刷新连接器或重启 WorkBuddy。
4. 直接发送下面的测试消息。**安装时不用选择笔记库，不用填写 API Key。**

```text
把下面内容整理成一篇 Obsidian 笔记。
笔记库绝对路径：D:\Obsidian\工作库
分类目录：技术研究\RAG
内容：增量索引只处理新增、修改和删除的文件，减少重复计算。
使用 personal-kb 工具完成保存，告诉我实际文件路径。
```

请替换为已经存在的库路径。Mac 示例：`/Users/你的用户名/Documents/工作库`。分类目录可以不存在，程序会在该库内创建。下次可以指定另一个库、另一个目录。生成的文件标为 `staged`，在 Obsidian 审核后可手动改为 `promoted`。

## 导入原有笔记

在安装页面点 **“准备语义检索”**，可关闭网页，后台继续下载依赖和模型。出现“已就绪”后，在 WorkBuddy 发送：

```text
为 D:\Obsidian\工作库 建立检索索引。
包含全部子目录的已有 Markdown，包括没有 status 字段的旧笔记；
排除 日记 和 模板 两个目录，保留原文件，以后自动同步。
如果是后台任务，先告诉我任务编号和状态。
```

程序按你指定的范围建立向量数据库，不改原笔记。`staged`、无效元数据、隐藏文件和链接目录不收录。已明确纳入的普通旧笔记会标识为“用户导入”，不会冒充人工审核。之后可说：

```text
只检索 D:\Obsidian\工作库 的技术研究目录，回答增量索引怎么工作，并引用原笔记路径。
```

同库再次指定索引范围会**替换**原范围。自动同步约每 30 秒检查一次；大库初次索引仍需要时间。长任务立即返回编号，WorkBuddy 可以查询进度，不需要在聊天内持续执行安装命令。

## 重开、恢复与视频

- 关机或停止服务后，再次双击安装入口。也可以使用安装目录内的 `Open Personal KB.cmd` / `.command`。重复打开会复用缓存和当前服务，此版不设置开机自启。
- 下载失败或任务中断：重新打开，在“后台任务”点击“继续 / 重试”。基础启动阶段失败则重新运行安装入口。
- 视频是可选功能：准备视频组件；有字幕时优先使用字幕。音频识别需要在页面保存你自己的 DashScope Key，相关音频会发送到该服务，服务费用以账户实际规则为准。不要把 Key 发到聊天里。
- 默认数据目录：Windows `%LOCALAPPDATA%\PersonalKB`；Mac `~/Library/Application Support/PersonalKB`。凭据、任务和向量库都在其 `data` 子目录。页面“维护与退出”可以停止服务。

## 已知试用边界

此包未做代码签名，也不是完全离线安装器。Windows 启动、WorkBuddy 特定版本的热加载与原生信任仍需实机反馈；配置保存不代表已经信任或连接。若旧版本配置也使用 `obsidian-personal-kb-host`，程序会拒绝覆盖，需在 WorkBuddy 中给旧条目改名或移除后再点接入。

仅处理你在对话中明确指定的路径。不要让 WorkBuddy 在沙箱中运行安装脚本；由你双击启动的本机服务承担安装、索引和视频任务。
