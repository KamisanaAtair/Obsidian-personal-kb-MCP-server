# Personal KB 0.5.0b3 试用指南

这一版既可以使用 WorkBuddy 的模型，也能在本机页面配置自己的文字、视觉和语音模型。视频截图会结合对应时间点前后的讲解，整理为 Obsidian 图文草稿。界面默认黑紫，右上角可切换白紫。

## 安装并打开

1. 使用 **[`codex/local-installer-preview` 分支源码 ZIP](https://github.com/KamisanaAtair/Obsidian-personal-kb-MCP-server/archive/refs/heads/codex/local-installer-preview.zip)**，或完整克隆这个分支。仓库默认 ASR 分支可能仍是旧版，请确认分支名。
2. **Windows x64**：选择“全部解压”，进入项目根目录双击 `install.cmd`。它必须与完整 `installer` 目录放在一起；源码已带 Windows uv，首次会联网准备私有 Python 和依赖，无需预装 Python。
3. **Mac**：远端源码未附带 Mac uv，不能直接双击 `install.command`。Apple 芯片、macOS 14+ 用户按 [README 开发运行步骤](README.md#开发与打包)启动当前源码，需要先安装 `uv`。新的 0.5 平台包没有远端下载入口。
4. 打开页面后核对页脚 **0.5.0b3**。如仍为旧版，先在旧页面“维护与退出”停止已知旧服务，再启动新入口；不要仅反复刷新旧页面。

[README 中的 0.4.0b3 平台包](README.md#历史安装包)仅是历史版本，不含本指南的图文视频和统一视觉 / ASR 设置。安装不会选择或扫描笔记库；每次任务再明确指定已有笔记库路径。

## 选择自己的模型

1. 打开 **“我的模型”**，点击 **“添加模型连接”**，选择千问、Kimi、GLM、DeepSeek、本地 Ollama 或自定义服务。
2. 千问需选择 **“按量 API”** 或 **“Token Plan”**；核对该入口的 Base URL 和匹配 Key。地址不填控制台网页或完整 `/chat/completions` 路径。输入框附近的帮助链接会解释填写方法。
3. 勾选服务实际支持的文字、视觉、语音能力，分别填写型号和 Key；点击 **“保存连接”** 后回到列表，可直接找到刚保存的连接并继续编辑。保存不等于启用，也不会自动消耗模型额度。
4. 在连接卡片上分别测试需要的能力。文字测试发简短请求、视觉测试发合成图片、语音测试发静音 WAV，可能产生 API 费用。列表获取失败时可手填官方型号，不必卡在“获取列表”。
5. 在“我的模型”点击 **“配置模型用途”**，选择 **“使用独立模型”** 和默认文字连接，按需覆盖整理、问答及关联；视觉、语音各自选择连接，再 **“保存并应用”**。

导航会切换独立页面视图，支持前进、后退及刷新。**“使用帮助”**提供 Q&A，输入框旁的帮助可打开具体问题并返回原位置。编辑草稿只留在当前页面会话中，刷新前请保存。

千问新平台的按量与 Token Plan 地址不同，两者都已提供预设；旧百炼连接不会自动迁移。新平台 Token Plan 可按兼容协议接入自定义工具，不能套用旧版 Coding Plan 指导。**本版尚未适配 Token Plan 新语音协议**，ASR 请单独配置通用千问 `qwen3-asr-flash` 或本版已支持的音频服务。详见 [README](README.md#千问新平台与旧百炼)。

更换设置只影响新任务；失败不会自动切换厂商或计费方式。宿主模式只转交文字生成，图文视频仍需视觉连接，无字幕时仍需 ASR。

### 填写或迁移 secret

0.5 本机服务的文字、视觉和 ASR Key 统一保存在系统凭据库，页面不回填；编辑时留空保留原 Key。系统凭据库不可用时明确报错，不转存明文。调用时 Key 用于对应服务认证，原文、截图或音频按任务发送给所选服务。

也可以展开 **“从本机 secret 文件导入 Key”**，按页面显示的路径将空 `secrets.env.example` 复制为 `secrets.env`，只在本机填写 `API_KEY=你的值`。选中已保存的目标连接后点击 **“导入本机填写的 Key”**。旧版 `data/credentials.json` 的 DashScope 字段可在 Qwen 连接中点击 **“迁移旧 DashScope Key”**。

导入不会自动启用路由。页面会确认目标及替换影响；成功写入系统凭据库并回读校验后，清空来源的密钥字段、保留其他内容，失败保留原值。空模板继续保留。不要把填写文件上传仓库或粘贴到聊天；旧 stdio 的凭据配置仍独立保留。

## 先整理一条文字笔记

在 **“本地任务”** 选择“整理一段内容为笔记”，填写：

- 已有笔记库的绝对路径，例如 `/Users/你的用户名/Documents/工作库` 或 `D:\Obsidian\工作库`。
- 保存目录，例如 `技术研究/RAG`，可留空；不存在的库内目录会被创建。
- 原文，例如“增量索引只处理新增、修改和删除的文件，减少重复计算”。

启用独立模型后点击“开始整理”，结果显示进度、正文、实际模型和保存路径。生成中内容仍待最终校验。完成后在 Obsidian 打开文件：新笔记强制 `status: staged`，人工审核后才改为 `promoted`。文字整理无需准备检索或视频组件。

宿主模式下，本地页面只准备资料与生成提示，请到 WorkBuddy 继续生成和保存；“资料已准备”不代表笔记已经落盘。

## 整理视频和重点图片

1. 在工作台点击视频转写的 **“准备”**；按上一节配置视觉连接。已有字幕优先使用，无可用字幕时才调用 ASR；没有 ASR 连接时只能处理带可用字幕的视频。
2. 在“本地任务”填写视频链接或本地视频绝对路径、笔记库及保存目录。视频限 **512 MiB、2 小时**。
3. 默认 **“纯文字”** 只整理字幕 / 转写。选择 **“图文结合”** 才会分析截图；可手动填写最多 8 个互不重复的视频内秒数，如 `90, 125.5, 240`。留空自动有限采样，最多 8 图，不保证涵盖所有重点。
4. 视觉模型先看真实截图及前后约 **30 秒**讲解，识别思维导图层级、流程箭头、图中事实和疑点；正文生成再结合完整时间轴组织解释，把图片放在相应段落旁。
5. 完成后在 Obsidian 检查正文与 `Assets/PersonalKB/...` 库内附件。图片使用相对引用，笔记仍为 `staged`。字幕时间与 ASR 分块时间分别标注，后者只是近似定位。

后台任务失败后可手动重试，优先复用完成的转写、抽帧和视觉分析；不会覆盖用户改过的笔记或附件。尚未完成的模型步骤仍可能重新计费。更详细的模型职责和导入说明见[图文视频指南](docs/video-notes.md)。

## 在 WorkBuddy 中自然语言使用

1. 在工作台点击 **“接入 WorkBuddy”**。程序备份并合并自己的连接条目，保留其他 MCP。
2. 在 WorkBuddy 连接器管理中找到 `obsidian-personal-kb-host`，完成原生信任；未出现时刷新连接器或重启 WorkBuddy。
3. 直接说明任务、路径和重点，例如：

```text
把这个视频整理成图文笔记：〈视频链接〉。
笔记库绝对路径：D:\Obsidian\工作库
保存目录：技术研究/视频
重点查看第 90、125.5、240 秒的思维导图，结合前后讲解解释中心主题、分支层级和它们的关系。
把无法确认的内容和时间精度标明，先保存为待审核草稿，完成后告诉我笔记和附件位置。
```

图文工具参数为 `video_mode="illustrated"`、`frame_times=[90,125.5,240]`。不指定时为纯文字。`ingest_content` 按当前生成方式处理：独立模式由服务完成生成，WorkBuddy 通过 `get_job` 等待结果；宿主模式取得 `prompt_for_host` 后生成正文，再调用 `ingest_content_finalize` 保存，保留提示中的图片占位符。

服务端管理模型连接和 Key，WorkBuddy 无需读取秘密。独立配置不会改变 WorkBuddy 自身的对话模型。配置保存、握手、原生信任和实际笔记保存要分别确认。

## 导入笔记、提问和关联

先在工作台准备语义检索组件；模型约 2.3 GB，另需运行依赖。准备好不会自动建立笔记库索引。

在“本地任务”选择 **“建立或更新检索索引”**，填写库路径、包含 / 排除目录并勾选授权。是否纳入无 `status` 的旧 Markdown、是否以后自动同步由你选择，也可向 WorkBuddy 明确提出同样的范围要求。同库重新指定范围会替换旧范围；原文件不修改。`staged`、无效元数据、隐藏文件和链接目录不收录。

随后可在本地页或 WorkBuddy 中提问、分析已 `promoted` 笔记的关联。独立模式返回答案、引用和模型信息；宿主模式返回生成资料。查询目录只能缩小当前授权范围。原笔记删除、修改、降级或范围变化会使旧结果失效，需重新发起任务。

## 重开、恢复与排障

- 安装器用户双击原入口或安装目录的 `Open Personal KB.cmd` / `.command`；开发运行用户重新执行启动命令。本版不添加开机自启。
- 后台任务中断后选择继续 / 重试。模型不会自动重试，手动重试可能产生费用；已完成的检查点优先复用。
- 安装器数据位于 Windows `%LOCALAPPDATA%\PersonalKB\data` 或 Mac `~/Library/Application Support/PersonalKB/data`；开发运行使用 `--data-dir` 指定的位置。
- Windows 显示 `Missing required file` 时，检查完整路径和解压目录，尤其是 `installer/vendor/windows-x64/uv.exe`。不要单独复制启动文件；如解压后文件消失，可检查安全软件隔离记录。按键只关闭失败窗口。
- 停止服务：展开页面 **“维护与退出”**，点击停止。更多路径和恢复说明见[安装指南](docs/SETUP_FROM_ZIP.md)。

本版已有自动化、真实媒体处理和隔离浏览器验证；真实收费模型质量、线上视频下载、新版 Windows 桌面操作及 WorkBuddy 原生操作仍待验收。详见 [README 验证范围](README.md#验证范围与试用边界)。
