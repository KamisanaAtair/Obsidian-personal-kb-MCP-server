# 本机安装与恢复

用户步骤见 [试用说明](../README-FIRST.md)。请使用平台安装包，完整解压后双击入口；无需复制 Skill 文件夹或向 WorkBuddy 发送两轮安装指令。

## 会看到的界面

1. 终端：首次准备私有 Python 和基础依赖。联网下载失败可重开，缓存保留。
2. 浏览器：本机连接、可选功能、后台任务、使用示例。没有选择笔记库页面。
3. 点击“安装并接入 WorkBuddy”：备份并合并本项目 HTTP MCP 配置。
4. WorkBuddy 原生界面：完成首次信任；必要时刷新连接器或重启客户端。
5. 返回同一对话发送业务指令。原会话是否自动接着执行取决于 WorkBuddy 版本，不能以配置保存推定会话已续跑。

## 稳定路径与重开

Windows：`%LOCALAPPDATA%\PersonalKB`。Mac：`~/Library/Application Support/PersonalKB`。

- `versions/`：隔离的基础运行时与应用副本。
- `data/`：凭据、持久任务、prepare 会话、模型和每库向量索引。
- `cache/uv`：依赖下载缓存。
- `Open Personal KB.cmd` / `.command`：持久启动入口，解压目录删除后也可使用。
- `logs/service.log`：启动诊断，反馈前自行确认不含隐私。

此版没有开机自启。重复启动会识别当前服务；不会杀死占用端口的未知进程。默认端口为 `32123`；有冲突时关闭已知旧版服务，或从本机终端以 `--port 32124` 启动并重新点击接入。

## 失败和升级

基础阶段失败：重开安装入口。可选功能失败：后台任务点继续 / 重试；缓存与已校验模型文件复用。退出或关机中断的运行中任务会标为“已中断”，由用户恢复。

新的应用副本会重新验证可选功能，模型缓存留在共享数据目录；需要时再次点准备即可。准备中仍能保存文字笔记，但检索、视频等后台任务共用队列，可能排队。

`mcp.json` 格式错误、同名非本安装器管理条目或链接路径会拒绝写入。不要用空文件覆盖既有配置。程序只维护自身条目，不修改信任记录。

可通过本机环境变量 `PERSONAL_KB_INDEX_URL` 指定可信 Python 包源；依赖 SHA256 校验保持启用。默认使用 PyPI，模型先尝试 ModelScope 固定版本，再尝试 Hugging Face 固定版本。网络和下载体积仍决定首次可选功能准备时间。
