# 视频图文笔记与 AI 设置

打开本机页面后，进入“我的模型”添加或编辑连接，再到“模型用途”分别选择文字、视觉和语音服务。输入框附近的帮助链接会打开相应 Q&A，并可返回继续填写。后续需要凭据的 AI 能力也应在此提供对应设置入口。

## 配置连接与能力

1. 添加或编辑连接，选择服务商并核对 Base URL；不要填写控制台网页或完整 `/chat/completions` 地址。千问预设区分新平台按量 API 和 Token Plan，需匹配计费方案与凭据；旧百炼连接保留原地址。
2. 勾选连接实际支持的能力，分别填写文字、视觉或语音型号。只用于视觉或语音的连接可以不填文字型号；语音能力还需按服务商文档选择 DashScope 或 OpenAI 兼容音频协议。
3. 手动填写 Key 并保存。同一个连接的多项能力共用一个 Key，但型号独立；本机免 Key 服务无需填写。只有声明相应能力的连接才会出现在对应路由中。
4. 为视觉理解和语音识别分别选择连接，点击“保存并应用”。这两项不会自动跟随默认文字模型；文字整理、问答、关联分析仍使用各自的文字路由。
5. 分别测试需要的能力。模型列表不可用时，可手动填写服务商提供的型号，保存后测试。保存、测试通过和启用是独立状态；配置变更后需重新测试。

新平台 Token Plan 可以通过兼容 API 配置，不能与通用按量地址混用。本版尚未适配套餐的 `qwen-audio-3.0-asr-flash` 协议，语音需另选通用千问 `qwen3-asr-flash` 或已支持的服务；不要只改型号套用旧协议。选择“使用宿主模型”只转交文字生成，视觉与 ASR 仍各自配置。具体入口与边界见 [README](../README.md#千问新平台与旧百炼)。

保存 Key 时，页面把值交给本机凭据服务；已保存的值不会返回页面。实际调用时，凭据会发送给所选连接的服务商用于认证。文字模型接收任务原文或检索片段，视觉模型接收选中的画面及相关讲解，需要转写时语音模型接收音频。调用前请核对服务地址、数据用途及费用。

文字测试使用简短请求，视觉测试使用合成图片，语音测试使用静音 WAV，均可能产生 API 费用。测试通过只说明对应能力的接口响应正常，不等于真实视频理解或转写质量通过，也不代表其他能力可用。

## 从本机 secret 文件导入

设置页会显示自动创建的空模板 `secrets.env.example` 和本机填写文件 `secrets.env` 的实际路径。复制空模板为填写文件，在本机编辑器中填写 `API_KEY=你的值`，然后选中并保存目标连接，点击“导入本机填写的 Key”。不要将文件内容粘贴到聊天或上传到仓库。

若本机存在旧 DashScope 凭据，可在选中的 Qwen 连接中点击“迁移旧 DashScope Key”。导入只更新当前选中的连接，不会自动分配到其他连接或启用路由；导入前会提示确认：系统凭据库写入并回读校验成功后，清空 `secrets.env` 对应密钥行或 `credentials.json` 中的 `dashscope_api_key` 字段，保留其他内容；失败时保留原值。目标已有 Key 时也会明确提示替换。空模板保留。完成后分别测试需要的能力。

## 在页面创建图文视频笔记

在“本地任务”选择“整理一段内容为笔记”，明确指定笔记库绝对路径、保存目录及视频链接。本轮视频处理限制为 512 MiB、2 小时，图文最多 8 帧。所有新视频请求使用同一时间标注流程，优先使用字幕；没有配置语音识别连接时，仅能处理带可用字幕的视频，不会自动回退到旧凭据。

- **纯文字**是默认方式，整理字幕或转写，不请求画面。
- **图文结合**会使用有限数量的画面，将每张画面与前后约 30 秒的讲解一起交给视觉模型，解释图示的结构、层级、箭头与讲解之间的关系，再组织为笔记。它不是仅提取图片中的文字，也不保证自动覆盖所有重点。
- 可手动指定最多 8 个时间点，使用以逗号分隔的非负秒数，例如 `90, 125.5, 240`；留空使用有限采样。手动时间点适合补充自动采样没有覆盖的图示。

结果会显示画面附件的库内相对路径、时间和定位依据。宿主模式的“资料已准备”阶段显示计划保存位置；宿主完成正文并保存后，才能在 Obsidian 中打开笔记及附件。字幕时间与音频分块时间会区分标注；分块转写只能提供近似定位，不应当作逐句精确时间戳。请结合原视频审核视觉解释、推断和时间关联。新笔记仍先保存为待审核草稿，是否正式收录由你决定。

## 在 WorkBuddy 中自然语言调用

把示例路径和链接换成自己的内容：

> 把这个视频整理成图文笔记：〈视频链接〉。笔记库是 `/Users/我/Documents/工作库`，保存目录是 `技术研究/视频`。使用图文模式，重点查看第 90、125.5、240 秒的画面，结合各时间点前后约 30 秒的讲解，解释结构图的层级、箭头关系及作者的论证。把时间精度和不确定的推断标明，先保存为待审核草稿。

MCP 调用对应参数为 `video_mode="illustrated"` 与 `frame_times=[90,125.5,240]`。不指定时使用 `video_mode="text"`；纯文字模式无需传入 `frame_times`。宿主仍按当前生成方式和工具结果继续处理，模型连接、Key 和视觉/语音路由需先在本机设置页配置。
